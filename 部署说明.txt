鲲之大，一锅炖不下 — 静态部署说明

1. 解压部署包，把 index.html 及其余文件放到静态网站根目录，无需安装依赖或构建。
2. GitHub Pages：将解压后的全部文件上传到仓库根目录；Settings → Pages → Deploy from a branch → main → / (root)。
3. 不要只上传 ZIP 文件，也不要多套一层文件夹。请保留 FONT-LICENSE.txt 和 THIRD_PARTY_NOTICES.txt。
4. 字体、图标、拼音与繁简转换库已内嵌在 HTML 中，无需字体 CDN；访问外部网站仍需网络。
5. 配置保存在当前浏览器的 localStorage。迁移前在旧页面“导出备份”，部署后在新网址“导入备份”。
6. 部署包包含默认网站列表，不包含你在其他浏览器中保存的个人配置。
7. 单文件 HTML 可直接预览；为可靠保存配置，日常使用建议通过 HTTPS 静态站点访问。
